这是正常现象 ​

AI 语言模型是概率生成模型——每次输出都是从概率分布中采样，而不是查数据库返回固定答案。

影响随机性的参数 ​

参数作用典型值
temperature控制随机程度，越高越随机0（固定）~ 2（极随机）
top_p控制采样范围0.1（保守）~ 1.0（开放）

需要稳定输出时怎么办 ​

python
response = client.chat.completions.create(
    model="claude-sonnet-4-5",
    messages=messages,
    temperature=0,  # 设为 0，输出最稳定
    top_p=1
)

TIP

temperature=0 时，相同输入大概率得到相同输出（但不是 100% 保证，上游模型更新也会影响输出）。

其他影响因素 ​

  • 上下文变化：哪怕只改了一个字，模型"看到的"就不同了
  • 系统 Prompt 差异：不同会话系统提示不同，输出风格会变
  • 模型版本更新：上游模型静默更新后，输出风格可能发生变化
