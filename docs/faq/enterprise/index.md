# 企业用户常见问题

## 接入方式

**Q：企业端 API 地址是什么？**

企业端接入地址：`https://b.pandatoken.com`

企业端相比个人端提供更高并发保障和专属支持。

**Q：支持专属定制吗？**

支持。企业客户可申请以下定制服务：
- 专属模型渠道配置
- 自定义并发限额
- 专属计费方案
- 私有化部署咨询

请联系企业客服了解详情。

---

## 服务保障

**Q：有 SLA 保障吗？**

有。企业客户享有服务可用性 SLA 保障，具体条款请联系企业客服获取协议文件。

**Q：有企业专属支持吗？**

有。企业客户享有：
- 专属客服对接
- 优先响应通道
- 技术集成支持

---

## 计费与发票

**Q：企业客户计费方式？**

按 Token 用量计费，支持对公转账、批量充值。支持开具增值税发票，请联系企业客服办理。
