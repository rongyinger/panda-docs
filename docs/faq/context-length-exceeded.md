## 错误原因

模型每次处理的文本有上限（上下文窗口），当你的请求超出这个上限就会报错。

实际消耗 = 系统 Prompt + **全部历史消息** + 本次输入 + 预留输出空间

很多用户不知道，客户端默认会把所有历史对话都带上，聊几十轮后 Token 会悄悄积累到超限。

## 不同模型上下文上限

| 模型 | 上下文窗口 |
|------|-----------|
| Claude 3.5/3.7 系列 | 200k tokens |
| GPT-4o | 128k tokens |
| DeepSeek V3 | 64k tokens |
| Gemini 1.5 Pro | 1M tokens |

## 解决方法

- **清空历史对话**：在客户端开启新对话，不要在一个超长对话里继续
- **缩短系统 Prompt**：检查是否有不必要的长系统提示词
- **换更大窗口的模型**：任务需要长上下文时，选 Claude 或 Gemini
- **代码层面**：实现历史消息裁剪，只保留最近 N 轮
