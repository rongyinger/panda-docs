# 个人用户常见问题

## 账号与充值

**Q：注册后有免费额度吗？**

暂时没有免费额度，注册后需要充值才能使用。

**Q：最低充值金额是多少？**

最低充值 $7 美元，无月费、无有效期限制。

**Q：支持哪些付款方式？**

支持微信支付、支付宝。如需发票请在充值时勾选开票选项，平台支持开具发票。

**Q：充值后余额没有到账怎么办？**

如充值后余额长时间未到账，请联系客服处理，提供充值截图和订单号以便快速核查。

## 接入与使用

**Q：API base_url 是什么？**

平台提供两个接入端点，根据你的使用场景选择：

| 端点 | 地址 | 适用场景 |
|------|------|---------|
| 个人端 | `https://c.pandatoken.com` | 个人开发者、轻量使用 |
| 企业端 | `https://b.pandatoken.com` | 企业客户、高并发场景 |

**Q：我用的是 OpenAI 官方 SDK，能直接换成熊猫算力吗？**

完全兼容。只需修改两处：

```python
# 原来
client = OpenAI(api_key="sk-...")

# 修改为
client = OpenAI(
    api_key="你的熊猫算力 Key",
    base_url="https://c.pandatoken.com/v1"  # 个人端
)
```

其他代码无需改动。

**Q：支持哪些模型？**

平台主推以下三大系列，覆盖主流使用场景：

- **Claude 系列**（Anthropic）：长文本、代码、文档分析
- **GPT 系列**（OpenAI）：通用对话、Agent、工具调用
- **Gemini 系列**（Google）：多模态、视频理解、长上下文

完整模型列表请查看平台控制台。

## 计费说明

**Q：怎么计费？**

按 Token 用量计费，输入和输出分别计价，无最低消费、无包月套餐，用多少扣多少。

**Q：能开发票吗？**

支持开具发票。充值时勾选开票选项，或充值后联系客服申请。
