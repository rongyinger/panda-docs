## 核心参数说明

### temperature（最重要）

控制输出的随机程度，范围 0-2：

| 值 | 效果 | 适合场景 |
|----|------|---------|
| 0 | 几乎固定，每次输出相同 | 数据提取、代码生成、格式化任务 |
| 0.3-0.7 | 略有变化，较稳定 | 问答、翻译、总结 |
| 0.7-1.0 | 有创意，自然流畅 | 日常对话、文案写作 |
| 1.0-2.0 | 创意强，但可能跑偏 | 头脑风暴、创意写作 |

### top_p

与 temperature 类似，控制采样范围，一般不需要同时调整两个：

- 需要稳定输出：`top_p=0.1`
- 正常使用：`top_p=1.0`（默认）

### max_tokens

单次输出最大 Token 数，根据任务设置：

```python
# 简单问答
max_tokens=512

# 代码生成
max_tokens=4096

# 长文写作
max_tokens=8192
```

## 推荐配置

```python
# 数据提取、结构化输出（要稳定）
{"temperature": 0, "top_p": 1}

# 普通对话（平衡）
{"temperature": 0.7, "top_p": 1}

# 创意写作（要创意）
{"temperature": 1.0, "top_p": 1}
```
