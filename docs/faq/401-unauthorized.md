## 错误原因

出现 401 通常是 API Key 的问题，排查以下几点：

- **Key 填写错误**：复制时多了空格、少了字符，或中间断行
- **Key 已失效**：被手动删除、禁用，或账户异常导致 Key 无效
- **Key 未激活**：新创建的 Key 偶尔需要等几秒才生效

## 解决方法

1. 回到熊猫算力平台，重新复制 API Key（点击复制按钮，不要手动选择）
2. 粘贴后检查 Key 首尾有无多余空格
3. 确认 Key 状态显示"正常"，未被禁用
4. 重新发起请求

::: warning 注意
API Key 一旦泄露请立即删除并重新生成，不要在公开代码或截图中暴露你的 Key。
:::
