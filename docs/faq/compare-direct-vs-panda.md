## 主要区别

| 对比项 | 官方 API | 熊猫算力 |
|-------|---------|---------|
| 注册门槛 | 需要境外手机号、信用卡 | 国内手机号注册，支持微信/支付宝 |
| 支付方式 | 境外信用卡 | 微信、支付宝 |
| 网络要求 | 需要科学上网 | 国内直连，无需代理 |
| 多模型 | 单家模型 | Claude/GPT/Gemini 统一接入 |
| 价格 | 官方定价 | 部分模型价格更优惠 |
| 发票 | 不支持国内发票 | 支持开具国内发票 |
| 技术支持 | 英文文档 | 中文支持 |

## 什么情况用官方

- 需要最新模型的最快访问
- 有境外支付能力且已有账号
- 对稳定性有极致要求且能接受官方价格

## 什么情况用熊猫算力

- 国内开发者，没有境外信用卡
- 想同时用 Claude、GPT、Gemini 多个模型
- 需要人民币支付和国内发票
- 企业采购需要合规
