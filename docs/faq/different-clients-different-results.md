## 原因

你调用的是同一个模型，但客户端决定了"模型看到的是什么"。

| 影响因素 | 说明 |
|---------|------|
| 系统 Prompt | 每个客户端预置了不同的系统提示，有的强调"简洁回答"，有的强调"详细解释" |
| 上下文裁剪策略 | 有的客户端截断历史，有的全量携带，影响模型"记忆" |
| temperature 默认值 | 有的客户端默认 0.7，有的默认 1.0，影响输出随机性 |
| Tool Call 开关 | 部分客户端默认开启工具调用，会改变模型行为 |
| 消息格式 | 不同客户端拼装 messages 的方式有细微差异 |

## 建议

想要稳定一致的输出，建议：
- 自己在代码里控制 system prompt，不依赖客户端预置
- 固定 temperature 参数
- 用 API 直调测试，排除客户端变量
