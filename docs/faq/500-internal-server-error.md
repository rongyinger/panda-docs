## 错误原因

500 表示服务器内部错误，通常不是你的问题：

- **上游模型服务异常**：模型服务临时故障
- **请求参数格式错误**：messages 结构不符合要求、传入了不支持的参数
- **服务暂时不可用**：上游在维护或过载

## 解决方法

1. **先检查请求格式**：确认 messages 数组格式正确，role 只能是 `user`/`assistant`/`system`
2. **等待后重试**：通常 1-2 分钟内会恢复
3. **排查特殊参数**：去掉非标准参数，用最简单的请求体测试
4. **联系客服**：若同一请求持续 500，把请求体（脱敏后）发给客服排查

```json
// 标准请求格式参考
{
  "model": "claude-sonnet-4-5",
  "messages": [
    {"role": "user", "content": "你好"}
  ]
}
```
