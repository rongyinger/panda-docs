## 系统提示词的作用

System Prompt 是每次对话开始前给模型的"角色设定和行为规则"，决定了模型的回答风格、能力边界和输出格式。

## 好的系统提示词结构

```
1. 角色定义（你是谁）
2. 任务范围（你能做什么/不能做什么）
3. 输出格式要求（怎么回答）
4. 语气风格（用什么语气）
```

## 示例对比

### ❌ 模糊的写法

```
你是一个助手，帮助用户解决问题。
```

### ✅ 清晰的写法

```
你是熊猫算力平台的技术支持助手。

你的职责：
- 帮助用户解决 API 接入问题
- 解答计费和账号相关问题
- 提供代码示例（Python/Node.js）

你不应该：
- 回答与平台无关的问题
- 承诺具体的 SLA 时间

回答风格：
- 简洁直接，先给结论再解释原因
- 代码示例要完整可运行
- 不确定的问题说"建议联系客服确认"
```

## 控制输出格式

```python
system_prompt = """你是数据提取助手。

每次提取结果必须严格按照以下 JSON 格式返回，不要有任何其他文字：
{
  "name": "人名",
  "phone": "电话号码",
  "email": "邮箱"
}

如果某个字段不存在，值填 null。"""
```

::: tip
System Prompt 越具体，模型行为越可预期。模糊的指令会导致模型自由发挥，输出不稳定。
:::
