## 两个端点对比

| 对比项 | 个人端 | 企业端 |
|-------|-------|-------|
| 地址 | `https://c.pandatoken.com` | `https://b.pandatoken.com` |
| 适用场景 | 个人开发者、学习测试 | 企业生产环境、高并发 |
| 并发保障 | 标准 | 更高 |
| 专属支持 | 无 | 有 |
| SLA 保障 | 无 | 有 |

## 怎么选

- **个人开发者、学习用途、小流量项目** → 个人端 `c.pandatoken.com`
- **企业生产环境、需要稳定性和支持** → 企业端 `b.pandatoken.com`，联系客服开通
