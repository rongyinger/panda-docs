正常响应时间参考 ​

场景预期等待时间
普通对话模型（短输入）1-5 秒
普通模型（长输入/长输出）5-20 秒
推理模型（o1/DeepSeek-R1）10-60 秒
图片输入额外增加 3-10 秒

常见原因 ​

1. 使用了推理模型 o1、o3、DeepSeek-R1 这类模型在回答前会进行"内部思考"，这个过程本身就需要时间，是正常现象，不是卡死。

2. 输入/输出内容过长 上下文越长，模型读取和生成耗时越长。

3. 高峰期排队 工作日白天和晚上是请求高峰，响应可能比平时慢 2-3 倍。

4. 图片或文件输入 多模态输入需要额外的编码处理时间。

5. Tool Call / Function Calling 工具调用需要多轮推理，每一轮都有延迟。

优化建议 ​

TIP

  • 不需要推理能力的任务，换用普通模型（claude-sonnet 代替 claude-opus）
  • 开启流式输出（streaming），用户可以边生成边看，体感更快
  • 减少不必要的历史消息携带
