## 主要模型系列

### Claude 系列（Anthropic）

**适合**：长文本处理、代码生成、文档分析、复杂指令遵循

| 模型 | 特点 |
|------|------|
| claude-opus-4 | 最强能力，适合复杂任务 |
| claude-sonnet-4-5 | 能力与速度均衡，日常首选 |
| claude-haiku-4-5 | 最快最省，适合简单任务 |

### GPT 系列（OpenAI）

**适合**：通用对话、Agent 工作流、工具调用

| 模型 | 特点 |
|------|------|
| gpt-4o | 综合能力强，支持多模态 |
| gpt-4o-mini | 轻量快速，性价比高 |
| o3 | 推理增强，适合复杂逻辑 |

### Gemini 系列（Google）

**适合**：多模态任务、超长上下文、视频理解

| 模型 | 特点 |
|------|------|
| gemini-2.5-pro | 超长上下文，多模态强 |
| gemini-2.0-flash | 速度快，性价比高 |

## 选型建议

::: tip
- 不确定用哪个？先用 `claude-sonnet-4-5` 或 `gpt-4o`，两者覆盖 80% 的场景
- 对成本敏感？用 `claude-haiku-4-5` 或 `gpt-4o-mini` 处理简单任务
- 需要处理超长文档？用 `claude-opus-4` 或 `gemini-2.5-pro`
:::
