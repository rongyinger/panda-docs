## 前言

最近模型圈竞争激烈，作者花了 400 元实测对比了四款热门大模型：Claude Opus 4.6、GPT-5.4、Kimi K2.6、DeepSeek V4 Pro，涵盖前端生成、3D 任务、网站开发、Agent 长程任务等多个场景。

## 测评场景汇总

### 1. 前端：信息图生成

测试模型的信息提炼能力、视觉排版能力和内容完整度。

结论：Kimi K2.6 和 DeepSeek V4 Pro 视觉冲击力更强；Claude Opus 4.6 内容提炼准确，关键信息无遗漏，但视觉效果一般；GPT-5.4 同样视觉较弱。

### 2. 前端：旅游网站（看图做设计）

测试图片理解和审美迁移能力。

结论：Claude Opus 4.6 和 Kimi K2.6 完成最好，均能理解参考图风格并迁移到设计中；DeepSeek V4 Pro 不支持多模态；GPT-5.4 图片加载异常。

### 3. 3D 任务（Three.js）

测试三维空间理解和 Three.js 组织能力。

结论：Claude Opus 4.6 和 Kimi K2.6 建模质量好，3D 场景流畅，完整实现"雪山+寺庙+塞尔达风格"；GPT-5.4 卡死无法交互；DeepSeek V4 Pro 建模粗糙。

### 4. 网站开发（摄影师作品集）

测试基于真实图片的网站生成能力。

结论：Kimi K2.6 表现突出，UI 细节丰富；Claude Opus 4.6 风格有特点，图片展示相对简单；DeepSeek V4 Pro 和 GPT-5.4 图片均无法加载。

### 5. Skills 任务（PPT 生成）

测试工具调用能力。

结论：四个模型均成功调用，效果相近，差异不大。

### 6. Agent 长程任务

复杂任务：联网搜索 + Word 生成 + Skills 调用 + 网站开发，四个模型均完成。

- 调研报告质量：Kimi K2.6 > Claude Opus 4.6 ≈ DeepSeek V4 Pro > GPT-5.4
- 网站生成：GPT-5.4 未能正确调用 skill，其余三个中规中矩

### 7. 费用对比（原文数据）

| 模型 | 本次花费 |
|------|---------|
| Claude Opus 4.6 | 约 16.4 美元 |
| GPT-5.4 | 约 22.8 美元 |
| Kimi K2.6 | 约 4 元人民币 |
| DeepSeek V4 Pro | 约 2.4 元人民币 |

## 原文总结

- **成本最优**：DeepSeek V4 Pro，但不支持多模态
- **性价比最高**：Kimi K2.6，能力强且价格低
- **Claude 和 GPT**：本次测试中未表现出明显代差，部分场景 GPT 表现较弱
