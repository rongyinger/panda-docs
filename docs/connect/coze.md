## 什么是 Coze

Coze 是字节跳动推出的 AI Agent 构建平台，支持快速搭建 AI 助手、工作流和插件，无需编程基础，可以发布到飞书、微信、抖音等多个平台。

## 在 Coze 中使用自定义模型

Coze 支持通过 **Model Provider** 功能接入外部模型，步骤如下：

1. 登录 [coze.cn](https://www.coze.cn)
2. 进入 **团队设置 → 模型管理**
3. 点击「添加模型」→ 选择「OpenAI 兼容」
4. 填写：
   - **API Key**：你的熊猫算力 Key
   - **Base URL**：`https://c.pandatoken.com/v1`
   - **模型 ID**：`claude-sonnet-4-6`
5. 点击「测试连接」确认成功
6. 保存后在 Bot 配置中选择该模型

## 搭建第一个 AI Bot

1. 进入 **Bot → 新建 Bot**
2. 在「模型」下拉框选择你刚添加的 Claude 模型
3. 在「人设与回复逻辑」填写系统提示词
4. 点击右上角「测试」验证效果
5. 满意后点击「发布」选择发布渠道

## 实用 Bot 配置示例

**客服 Bot 系统提示词：**
```
你是熊猫算力平台的智能客服助手。

职责：
- 解答 API 接入相关问题
- 解释计费规则
- 处理常见报错

回复风格：
- 简洁直接，先给结论
- 提供可复制的代码示例
- 无法确定的问题引导用户联系人工客服
```

::: tip
Coze 的工作流功能可以实现多步骤 Agent，比如"收到用户问题 → 搜索知识库 → Claude 生成回答 → 返回用户"，配合熊猫算力的多模型支持，可以在不同步骤用不同模型，降低整体成本。
:::
