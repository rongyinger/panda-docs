# 熊猫算力平台 · 快速上手指南

从注册登录到获取 API Key，完整操作步骤，适合外部用户和开发者快速接入。

::: tip 本教程分为三个阶段
**账户准备 → 平台体验 → API 接入**，按步骤操作，约需 **5–10 分钟**完成全部配置。
:::

## 整体流程概览

| 阶段 | 步骤 | 内容 |
|------|------|------|
| 账户准备 | 1–4 | 登录、查看余额、充值 |
| 平台体验 | 5–7 | 操练场对话、选模型 |
| API 接入 | 8–12 | 创建令牌、获取 Key 和 Base URL |

---

## 第一阶段：账户准备

### 第 1 步：登录平台账户

打开浏览器，访问 `https://www.pandatoken.net`，点击右上角**登录**，输入用户名/邮箱和密码，点击**继续**。

![填写用户名与密码后点击「继续」](/images/guide/step01-login.png)

::: tip 还没有账户？
点击登录框下方的**注册**链接完成注册后再登录。
:::

---

### 第 2 步：进入钱包管理，查看余额

登录后进入**数据看板**，可看到当前余额。点击余额卡片旁的**充值**按钮（或左侧**钱包管理**）进入充值页面。

![①点击余额卡片 → ②点击「充值」按钮](/images/guide/step02-wallet.png)

---

### 第 3 步：输入充值金额

在**充值数量**输入框填写美元金额（如 `5`，即 $5，实付约 34.75 元人民币）。也可直接点击下方预设套餐（$10、$20、$50、$100……）。

![③输入金额 → ④选择支付方式](/images/guide/step03-recharge.png)

::: warning 注意
充值金额为**美元计价**，页面会实时换算显示人民币实付金额。
:::

---

### 第 4 步：选择支付方式并完成支付

点击**支付宝**或**微信**，跳转扫码完成付款，余额自动到账。

---

## 第二阶段：平台体验

### 第 5 步：进入「操练场」

点击左侧导航栏**操练场**，进入模型在线对话界面，是调试 Prompt 的理想场所。

![左侧配置模型参数，右侧进行 AI 对话](/images/guide/step05-playground.png)

---

### 第 6 步：选择要使用的模型

点击左侧「模型」下拉菜单，展开完整模型列表，可选 **GPT-4o**、**Claude 系列**、**Gemini**、**即梦**、**可灵（Kling）** 等，按需选择。

::: tip 计费说明
文字模型按 Token 计费，图/视频生成模型按次计费，可前往**模型广场**查看详细价格。
:::

---

### 第 7 步：输入问题，开始对话

在右侧对话框底部输入框输入问题，按 `Enter` 或点击发送即可获得回复。

> **📌 提示**：每次对话消耗账户余额，可在「使用日志」查看详细消耗记录。

---

## 第三阶段：API 接入

### 第 8 步：进入「令牌管理」

点击左侧导航栏**令牌管理**，查看所有已创建的 API Key，包含名称、状态、余额限制、可用模型等信息。

![令牌管理页面 — 查看、新增、复制 API Key](/images/guide/step08-token-list.png)

---

### 第 9 步：添加新令牌（API Key）

点击**添加令牌**，填写名称，可选设置额度限制和可用模型范围，确认后生成新的 API Key。

::: tip 最佳实践
建议为每个项目创建独立令牌，方便按项目追踪用量或单独禁用。
:::

---

### 第 10 步：复制 API Key（密钥）

在令牌列表中，点击密钥一栏的 📋 复制图标，将完整 API Key 复制到剪贴板。

::: warning 重要：请妥善保管 API Key
API Key 是访问凭证，**不要泄露或提交到公开代码仓库**（如 GitHub）。
:::

---

### 第 11 步：复制 API Base URL

回到平台首页，复制页面中央展示的接入地址：

```
https://www.pandatoken.net/v1
```

![点击地址框右侧复制图标，获取 Base URL](/images/guide/step11-base-url.png)

::: tip 接入任意工具
在代码或工具（Dify、Cursor、OpenAI SDK 等）中，将原有的 `https://api.openai.com` 替换为上方地址，填入 API Key，即可调用平台所有模型。

**Python 示例：**

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxx...",   # 你的令牌密钥
    base_url="https://www.pandatoken.net/v1"
)

response = client.chat.completions.create(
    model="claude-3.7-sonnet-20250219",
    messages=[{"role": "user", "content": "你好！"}]
)
print(response.choices[0].message.content)
```
:::

---

### 第 12 步：在模型广场查看所有可用模型与价格

点击顶部导航**模型广场**，查看平台聚合的全部 **71 个模型**，支持按供应商（Anthropic、OpenAI、Google、DeepSeek、即梦、快手等）、计费类型筛选。

![模型广场 — 查看输入/输出价格（$/1M Tokens），点击复制图标获取模型 ID](/images/guide/step12-model-market.png)
